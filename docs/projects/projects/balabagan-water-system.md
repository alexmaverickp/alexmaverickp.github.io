# Water System Planning Support Through GIS Mapping and Hazard Assessment

This project involved developing a GIS mapping package supporting water system planning and feasibility assessment in Balabagan, Lanao del Sur.

The work combined watershed delineation, service area mapping, intake source mapping, flood hazard assessment, landslide hazard assessment, and infrastructure planning maps to support decision-making and reporting requirements.

## Key Outputs

- Watershed Delineation
- Service Area Mapping
- Intake Location Mapping
- Flood Hazard Mapping
- Landslide Hazard Mapping
- Infrastructure Planning Maps
- 16+ Report-Ready Map Layouts

## Tools & Data

- QGIS
- Google Earth Engine
- Copernicus DEM
- OpenStreetMap
- UP NOAH

## Role

GIS Analyst and Cartographer
